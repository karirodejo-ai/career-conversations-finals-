# Deploy Career Conversations Website to GitHub Pages

## Prerequisites
- Git installed on your computer
- GitHub account

## Step 1: Initialize Git Repository (if not already done)
```bash
cd "c:\Users\karir\Downloads\career-conversations-html-css-js"
git init
git add .
git commit -m "Initial commit: Career Conversations website with enhanced CSS"
```

## Step 2: Create Remote Repository on GitHub
1. Go to https://github.com/new
2. Repository name: `career-conversations` (or your preferred name)
3. Description: "Career coaching website for Dr. Faith - personalized career mentoring and coaching sessions"
4. Choose: **Public** (for GitHub Pages to work)
5. Click **Create repository**

## Step 3: Connect Local Repository to GitHub
Replace `YOUR_USERNAME` with your GitHub username:

```bash
git remote add origin https://github.com/YOUR_USERNAME/career-conversations.git
git branch -M main
git push -u origin main
```

## Step 4: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** (gear icon)
3. Scroll down to **Pages** section
4. Under "Build and deployment":
   - Source: Select **Deploy from a branch**
   - Branch: Select **main** and **/root** folder
   - Click **Save**

## Step 5: Your Website is Live!
Your website will be available at:
```
https://YOUR_USERNAME.github.io/career-conversations
```

Or if you have a custom domain, configure it in the Pages settings.

## Troubleshooting

### Site not showing up?
- Wait 5-10 minutes for GitHub to deploy
- Check Pages settings are enabled
- Make sure `index.html` is in the root directory
- Verify branch is set to `main`

### Images not loading?
- Check image paths are relative (e.g., `assets/image.png`)
- Verify image files exist in the `/assets` folder
- File names are case-sensitive on Linux servers

### Custom Domain?
If you own a domain, add it in Pages settings and update your DNS records.
